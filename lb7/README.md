# Lab 7: Multi-Dimensional Data Structures

## 1. Task Description
This laboratory explores two-dimensional internal memory boundaries representing typical matrix/tensor datasets.

**Task 7.1: Multi-key sorting and matrix evaluation**
Allocates an $8 \times 5$ target topology tracking hierarchical swaps along column anchors (`col[0]`, `col[1]`, `col[3]`). Processes values evaluating arithmetic criteria dynamically zeroing nodes. Modeled robustly against iterative loops vs recursive node hops.
